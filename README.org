* mdired

*mdired* is an Elisp package that provides commands for running [[https://en.wikipedia.org/wiki/Single_instruction,_multiple_data][SIMD]]-style operations on marked Dired items.

Please be advised: *mdired* can make irreversible changes to the file system if no prior checkpoint (typically via a source code management or backup tool) is available. Exercise caution.

* Features

- ~mdired-copy~ :: copy a single file to multiple directories.

- ~mdired-do-command~ :: run an Elisp command on multiple files.

- ~mdired-compile~ :: run ~compile~ on multiple directories.

- ~mdired-byte-recompile~ :: byte-compile selected files or directories.


* Requirements

- GNU Emacs 30.1+


* Usage

Refer to the [[https://kickingvegas.github.io/mdired/][mdired User Guide]] for guidance on usage.

* Install

If manually installed then ensure that ~mdired.el~ is in ~load-path~.

If installed via ~package-install~, then all *mdired* commands are auto-loaded.
